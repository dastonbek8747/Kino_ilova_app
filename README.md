# 📱 Kino Ilova (Android)

**Android** (Java) uchun yozilgan kino ilovasi. Kotlin DSL Gradle bilan quriladi.

---

## ✨ Imkoniyatlar

- 🎬 Kino ro'yxati va ko'rish
- 📱 Android native interfeys
- 🏗 Gradle (Kotlin DSL) build tizimi

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Java** | Asosiy til |
| **Android SDK** | Platforma |
| **Gradle (KTS)** | Build tizimi |

---

## ⚙️ O'rnatish va qurish

```bash
git clone https://github.com/dastonbek8747/Kino_ilova_app.git
cd Kino_ilova_app
./gradlew build
```

**Android Studio**da ochib, emulyator yoki qurilmada ishga tushiring.
